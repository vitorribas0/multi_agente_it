# Ciencia Dados

1. Inspecione shape, colunas, tipos, nulos e amostra antes de analisar.
2. Use código reproduzível no sandbox; mantenha o dataset original e salve derivados na pasta da sessão.
3. Valide contagens, denominadores e percentuais antes de publicar resultados.
4. Para texto, normalize acentos, caixa e pontuação antes de buscar termos.
5. Para clustering, exclua IDs/códigos, padronize features, compare valores de K e reporte múltiplas métricas.
6. Trate interpretações de grupos como hipóteses, não como verdade causal.
7. Antes de classificação massiva por LLM, siga obrigatoriamente a confirmação em [analise-massiva.md](references/analise-massiva.md).

Leia [fluxo-analitico.md](references/fluxo-analitico.md) para análises estatísticas, clustering, outliers e gráficos.
